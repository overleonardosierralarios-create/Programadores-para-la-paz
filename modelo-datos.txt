MODELO DE DATOS - PETICIÓN EN 3 CLICS

ENTIDADES Y ATRIBUTOS:

Causa
- id (INT, Primary Key, Auto_increment)
- titulo (VARCHAR(150))
- descripcion (TEXT)
- fecha_creacion (TIMESTAMP)

Apoyo
- id (INT, Primary Key, Auto_increment)
- causa_id (INT, Foreign Key hace referencia a Causa.id)
- nombre_ciudadano (VARCHAR(100))
- fecha_apoyo (TIMESTAMP)

EXPLICACIÓN DE LAS ENTIDADES:
- Entidad "Causa": Sirve para almacenar el registro centralizado de la problemática, solicitud o propuesta que la comunidad desea impulsar, identificándola de forma única.
- Entidad "Apoyo": Sirve para registrar individualmente cada voto, respaldo o firma digital que los ciudadanos otorgan a una causa específica. Utiliza una relación de clave foránea (causa_id) para asociar directamente cada apoyo con la causa correspondiente, permitiendo realizar métricas, sumatorias y validaciones de participación.
