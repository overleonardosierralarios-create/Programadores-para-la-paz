¿Qué ocurre cuando ejecutas node server.js?
Al ejecutar el comando, Node.js interpreta el código del archivo, inicializa el framework Express y activa los canales de escucha del sistema para empezar a recibir solicitudes HTTP externas.

¿Qué mensaje aparece en la terminal?
Aparece el mensaje de confirmación programado: "Servidor ejecutándose en puerto 3000".

¿Qué sucede cuando visitas la ruta /estado?
El navegador web envía una petición GET al servidor y este le devuelve una respuesta estructurada en formato JSON que contiene el estado operativo y el nombre del servicio, viéndose así:
{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
